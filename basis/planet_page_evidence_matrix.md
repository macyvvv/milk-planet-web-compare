# Planet page evidence matrix

## 目的

ShandyLoveとmilkplanet新宿のメニュー画像版を、HTML版へ移す際の正本、意味情報、視覚判断、実装責務、監査状態を追跡するためのマトリクス。これは完成ページの見た目を保存するだけでなく、次回に同じ判断を再現し、異なる判断を意識的に選べるようにするための学習資料である。

## 範囲と判定方法

- 対象ページ: `proposal/branch5/shop/shandy/menu/` と `proposal/branch5/shop/shinjuku/menu/`、および対応する `menu-html/index_3.html`
- 対象アセット: 各`menu/images/`配下の全ファイル。派生ヒーローも原典との関係を含めて記録する。
- 対象情報: 画像内の歓迎、規則、価格、商品、特典、告知、更新情報、画像自体が持つ店舗固有の造形。
- 対象外: 共通ナビゲーション画像、解析タグ、共通ライブラリの個別監査。これらはページシェルの別監査対象とする。
- `静的照合済み`: 原典画像、原典HTML、`index_3.html`、店舗CSSを読み取り、画像を目視確認した状態。ブラウザでの実表示適合を意味しない。
- `未確認`: 情報の正本または実表示がこのマトリクスだけでは確定できない状態。

## 3. 「人間が設計した」と判断するための哲学的な評価軸

外見だけから人間制作／AI制作を確定することはできない。ここではAI使用の有無ではなく、完成物に判断の責任と根拠が残っているかを評価する。これは、GOV.UKのユーザー起点・データ起点・公開、NHSの成果・文脈・仮説検証・反復、Microsoft ResearchのWeb制作における同質化と`productive friction`、InterfaceKitの「AI使用ではなく未検証出力の受容が問題」という整理を、Planet向けに翻訳したもの。

| 評価軸 | 人間の設計判断が残る状態 | AI場当たり生成に見える状態 | Planetでの検査 |
| --- | --- | --- | --- |
| Situatedness／状況への根ざし | その店舗・利用者・運用にしか成立しない理由がある | 店名・色・ロゴを替えても同じページが成立する | Swap test、店舗別情報順・密度・例外を確認 |
| Priority／優先順位 | 最初に知るべき料金・条件・歓迎・予約等が定義されている | hero、カード、装飾が先行し、重要情報が後回し | 最初の行動と到達距離を記録 |
| Authority／正本への忠実さ | 文言、価格、特典、画像の役割に根拠と更新主体がある | 空白をもっともらしいコピーや装飾で補う | Source mapと正本列を全行埋める |
| Commitment／非採用と犠牲 | 何を残し、何を捨て、何を犠牲にしたか説明できる | すべてを盛り、選択の結果が見えない | Commitments、Deliberate exclusions、Tradeoffsを照合 |
| Productive friction／意図的な抵抗 | 共通テンプレートに戻す前に、原典の癖・更新事情・制約を引き受ける | 安全なカード、均等な余白、無難なグリッドへ平均化する | Flattening test、Pattern repetition test |
| Content reality／実コンテンツへの耐性 | 実際の長文、価格、欠品、更新、低速表示に対応する | ダミー文・理想状態・スクリーンショットだけで完成扱い | 実原稿、長い商品名、画像欠落、低速時を確認 |
| Continuity／時間とページをまたぐ一貫性 | 正本・更新・判断ログが次回の変更へつながる | 一回の生成結果だけが正本になり、理由が失われる | work packet、decision log、release stateを残す |
| Accountability／最終責任 | 採用・保留・却下と確認者が明確 | 「見た目が整っている」ことだけで公開する | 独立監査、未検証範囲、残存リスクを記録 |

## 4. MECE再検査の結果

### 充足した範囲

- 23個の`menu/images/`アセットをページ別に列挙した。
- `content / hero / texture`の役割と、HTML化・画像保持・派生・意図的非表示を分けた。
- Shandy固有のスキン化・赤・高密度・販促画像と、新宿固有の歓迎画像・ポイント更新を共通原則から分離した。
- 画像の欠落、画像とHTMLの重複、情報順、更新正本、クロップ境界を別の判断領域として記録した。
- AIらしさを装飾の逆張りとしてではなく、根拠不足、平均化、未検証、責任不在として評価する軸を追加した。

### まだMECEではない範囲

- 各商品名・価格の一件ごとの機械的な差分表ではない。現行は原典画像の意味ブロック単位であり、数値の完全一致は別のcontent diffが必要。
- 共通ページシェル、ナビゲーション画像、外部フォント、JavaScript、解析タグは本表の対象外。ページシェル監査を別途行う必要がある。
- ブラウザ表示、キーボード操作、W3C相当検証、低速時の画像失敗は、この静的マトリクスだけでは証明できない。
- 利用者の来店・予約・注文への到達時間や判断成功率は未計測で、哲学が事業成果へ接続したかは未検証。
- 外部研究は設計軸の候補を与えるものであり、Planetページの人間らしさを証明するものではない。
