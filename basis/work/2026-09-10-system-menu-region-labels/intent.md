# Change

Unify the ten system-menu store labels with one display naming policy, selecting the region suffix only if it remains readable at the actual submenu width.

## Viewing situation

- FACT: The shared system submenu currently appends `｜新宿` to only two store labels while the other labels use no suffix or embed an English region abbreviation.
- USER: Add region names consistently; use `ラオス` for LAOS.
- CONSTRAINT: The menu is generated by shared `proposal.js`, so the change affects every Branch5 consumer.

## Business and human outcome

- INFERENCE: Consistent store labels reduce ambiguity when a visitor compares domestic and overseas locations.
- INFERENCE: A concise, repeated `店舗名｜地域` pattern is easier to scan than a mixture of suffixes and unsuffixed names.

## Source lock

- FACT: Region labels are based on the existing store page titles, descriptions, and address blocks in `proposal/branch5/shop/<store>/index.html`.
- FACT: Existing menu URLs and store order in `SYSTEM_MENU_ITEMS` are canonical for this navigation.
- FACT: `proposal/branch5/navigation.css` already permits child-link wrapping; no CSS change is planned unless the audit finds a concrete defect.

## Hierarchy

1. Preserve the official store-name portion and existing order.
2. Prefer one consistent region suffix only when it does not create word fragmentation or redundant overseas labels.
3. Otherwise use the existing official store identifier for every displayed store label.

## Commitments

1. Evaluate the same `店舗名｜地域` policy for all ten system-menu entries.
2. Adopt the identifier-only fallback when the suffix harms readability; retain `BKK` and `LAOS` as existing identifiers.
3. Verify labels, links, keyboard/menu behavior, and wrapping at required widths.

## Deliberate exclusions

- Do not change store page titles, SEO copy, addresses, HTML menus, or image assets.
- Do not change the remote shopping submenu.
- Do not rename the underlying official store identifiers or alter destination URLs.
- Do not add a new CSS abstraction or normalize other branches.

## Tradeoffs and unknowns

- TRADEOFF: BKK and LAOS remain in the brand-facing store identifier while the suffix adds a Japanese region label for visual consistency; this creates intentional repetition for overseas entries.
- UNKNOWN: The available submenu width may cause one or more long overseas labels to wrap; this must be judged in the browser rather than by character count alone.
