# Retrospective

## Observed event

- タイトル面を青へ変更した結果、淡色背景を持つ店舗ロゴ画像の矩形が浮いた。
- 価格・ポイント一覧の汎用グリッドが、`3ポイント`と`18ポイント`を語中で分断した。
- 店舗色として選んだ青が、通常サイズのナビ・注記・価格で十分なコントラストを持たなかった。
- 比較用の`Visual Variant 3`がブラウザタイトルへ残っていた。

## Detection phase

- すべてCheck（独立監査）で検出した。

## Missed gate or cause

- ロゴ画像の背景色とタイトル面の隣接関係を、実表示前の色ペアとして確認していなかった。
- 数値・単位・閾値を一般的な`minmax(0, 1fr)`へ入れ、意味単位の最小幅を定義していなかった。
- 色の規格計算を実装後に行い、候補色の選定へ前倒しできていなかった。
- 制作途中のtitle文言を公開表示監査の対象に含めていなかった。

## Generalizable rule

- ロゴ・バナーに背景が焼き込まれている場合は、画像単体ではなく「画像背景と隣接面」の組み合わせを初期表示・sticky表示・モバイルで監査する。
- 価格、ポイント、時間、会員ランクなどの閾値は、テキスト全体ではなく意味単位として折返しルールを設計する。
- 店舗色は候補値の段階で、実際の文字サイズ・背景面とコントラスト表を作る。
- title、description、alt、コメント、クラス名に制作途中の比較名称が残っていないか公開前に検査する。

## Skill or validator change

- 今回はページ修正のScopeを優先し、Skill本体・共通CSS・validatorは変更しない。
- 上記4規則を次回の`visual-fidelity`およびページ公開前lintへ昇格する候補として記録した。

## Follow-up

- 次回Skill更新時に、焼き込み背景ロゴ、意味単位トークン、公開メタデータ残留を自動検査できるか検証する。
- 新しいロゴ資産を採用する場合は、原典所有者と正本を確認してから別変更として扱う。
