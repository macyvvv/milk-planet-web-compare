# WBS(作業分解と完了条件)

元指示書26章のPhase構成を踏襲する。各Phaseの完了条件(DoD)を明記し、Phase 0完了時点でユーザー承認を得てから
Phase 1以降へ進む。

## 実装状況サマリ(2026-07-28時点)

Phase 0(設計)承認後、Phase 1〜5のコード実装、およびPhase 6のうち単体テストを一通り実装した。
`proposal/branch101/app/` で `npm run lint` / `npx tsc --noEmit` / `npm test` / `npm run build` が
すべて成功する状態。ただし以下は **未達・未検証** であり、この状態を「完成」とは呼べない。

- **実DB未接続**: D-001(ホスティング先)が未確定のため、マイグレーション(`prisma migrate deploy` +
  `prisma/manual-constraints.sql`)を一度も実データベースに適用していない。DB制約(排他制約・部分一意
  索引)がPostgreSQL上で実際に機能するかは未検証。
- **統合テスト・E2Eテストは一部のみ**: pure logic 51件に加え、bootstrap・SQLite制約・監査Triggerを
  検証した。ブラウザE2Eと全権限境界の自動化は継続課題。
- **アカウント管理**: `/admin/users` と `/admin/roles`、初期SU bootstrap、ロック解除、
  コード再発行、パスワード再設定許可を実装済み。
- **CSVインポートはCASTS/AVAILABILITYの2種のみ**: MEMBERSHIPS/EVENTS/CONFIRMED_SHIFTSのインポートは
  未実装(エクスポートは7種すべて実装済み)。
- **LINE文章テンプレートは編集不可**: `notification_templates` テーブルは用意したが、文章フォーマットは
  `lib/modules/notifications/notification-text.ts` にハードコードしており、管理画面からの編集機能はない。
- **ピリオド自動生成の定期実行(D-003のB経路)は未配線**: 参照時の冪等生成のみ動作し、
  スケジュール実行(Vercel Cron等)からの事前生成は未実装。
- **アクセシビリティ・モバイル実機確認は未実施**。
- 詳細画面仕様(`screen_spec.md`)は骨子から大枠を実装したが、入力検証の細部(全項目のエラーメッセージ等)
  は実装しながら決めた部分があり、`screen_spec.md` 自体は更新していない(実装とドキュメントの乖離あり)。

以下のPhase別テーブルの「完了条件」列は元指示書ベースの理想形であり、上記の理由により
**E2E/統合テストを要する完了条件は現時点で未達**。コードとしての機能実装は完了しているが、
「Definition of Done(元指示書27章)」を満たしたとは言えない状態である。
